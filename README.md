# JichitaiStudy（自治体スタディ）

> 地方公務員法・地方自治法など、自治体職員の基礎知識を学ぶための学習Webアプリ

## 概要

JichitaiStudy は、地方公務員法・地方自治法を中心とした自治体職員の基礎知識を、隙間時間にスマホで学べる単一HTMLファイルの学習アプリです。

地方公務員制度や地方自治制度を学習する人向けに、四択問題・○×問題・空欄補充問題の3形式で、全121問を収録しています。

## 特徴

- **オフライン動作** — 単一HTMLファイル。ブラウザで開くだけで動作し、サーバーは不要
- **10問ずつのセット出題** — 一気に全問解く必要がなく、隙間時間に取り組める
- **5章構成** — 法律の基礎／地方自治／地方公務員制度／財政と税／過去10年の主な法改正
- **3つの出題形式** — 四択・○×・空欄補充
- **学習履歴の自動保存** — ブラウザのlocalStorageに正答率・学習回数・間違えた問題を記録
- **間違えた問題だけ復習モード** — 弱点を集中的に克服できる
- **頻出ポイント10問** — 最重要問題のみピックアップ
- **法改正10問** — 過去10年の改正点に特化したモード
- **モバイル対応** — スマホでも快適に操作できるレスポンシブデザイン

## 収録範囲

| 章       | タイトル             | 問題数    |
| -------- | -------------------- | --------- |
| 第1章    | 法律の基礎           | 14問      |
| 第2章    | 地方自治             | 27問      |
| 第3章    | 地方公務員制度       | 28問      |
| 第4章    | 財政と税             | 37問      |
| 第5章    | 過去10年の主な法改正 | 15問      |
| **合計** |                      | **121問** |

第5章では、会計年度任用職員制度（令和2年）、定年引上げ・役職定年制（令和3年〜）、定年前再任用短時間勤務制（令和5年）、会計年度任用職員への勤勉手当支給（令和6年）、地方自治法の補充的指示権・公金収納事務のデジタル化（令和6年）など、近年の重要な法改正を扱っています。
